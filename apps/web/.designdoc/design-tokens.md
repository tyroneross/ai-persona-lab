## AI Prompt Pack

Paste these into a coding agent to implement screens in this system:

- Use accent #5E5CE6 (text #FFFFFF) for the single primary action on each screen. Accent means 'do something here' — never decorate with it.
- Surfaces: page #FFFFFF, grouped card #F5F5F7, 1px #E5E5EA borders. One border around a related group; dividers between rows, never per-item borders.
- Type ladder is strict (title -> body -> meta, no 4th size). Font 'Custom Brand', system-ui, sans-serif; headings weight 700, body weight 400.
- Numeric/data display style: tabular (apply to timers, stats, tables).
- Spacing on an 8pt grid, spacious density. Content >= 70% of pixels; whitespace before borders.
- Button radius 8px; button shape 'glass'.
- Elevation: 'glass'. Prefer whitespace and hairline borders over heavy shadows.
- Navigation: active state 'text-underline', tab style 'icon-label'. Selected nav uses text weight + indicator, not a background pill (unless picked).
- Motion: 'push-slide' transitions at 'expressive' intensity. Keep motion purposeful.
- Components: list separator 'none', empty state 'icon-text', notifications 'inline'. Status = text color + icon, never a filled badge.
- [ios] 44px minimum touch targets; SF Symbols for tab icons.
- [macos] Compact control heights — this is a desktop window, never oversize buttons.
- Revealed preferences (the walk's picks): Platform Target: Web; Primary Navigation Structure: Top Nav Bar; Accent Color Application: Expressive Accent Spread; Display & Heading Treatment: Custom Brand Font; Primary Button Shadow & Depth: Glass / Frosted; List Item Separator: Whitespace Only.
