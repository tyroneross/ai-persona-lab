# AI Persona Lab web

The Next.js application for the AI Persona Lab library and council API. The
canonical CLI/plugin lives two directories above this one.

From the repository root, run `npm run web:install` then `npm run web:dev`.
See [deployment](docs/deployment.md) and
[consolidation](../../docs/repository-consolidation.md) for data and build paths.
The imported `docs/architecture.md` and planning records preserve their original
design context; the consolidation record governs the current source layout.
